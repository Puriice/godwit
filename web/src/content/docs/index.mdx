<CardGrid stagger>
	<Card title="Multiple targets" icon="seti:db">
		Apply the same migrations to any number of PostgreSQL, MySQL/MariaDB and SQLite
		databases. One set of files can serve all of them.
	</Card>
	<Card title="One file per migration" icon="document">
		Plain SQL with optional per-engine blocks, so dialect differences stay in the
		same file.
	</Card>
	<Card title="TUI and CLI" icon="terminal">
		Every action in the TUI also exists as a command, for scripts and CI.
	</Card>
	<Card title="Runs survive quitting" icon="rocket">
		Migrations run in a detached worker, so closing the terminal doesn't interrupt
		them.
	</Card>
	<Card title="Safe by default" icon="approve-check">
		Checksums detect edited migrations, locks stop concurrent runs, and a failed run
		is flagged until you resolve it.
	</Card>
	<Card title="Batch processing" icon="random">
		Backfill big tables in repeated, separately committed passes instead of one
		giant transaction.
	</Card>
